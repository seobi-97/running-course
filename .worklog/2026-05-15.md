## 주요 결정 사항
- **상태 관리**: 기존 `useCoursePath` 모듈-스코프 싱글턴 composable → React Context + Provider 로 대응.
  Zustand 등 미요청 의존성을 피하고 내장 Context 사용 (소비자 2개, 소규모 앱이라 리렌더 비용 무시 가능).
- **API 관리 (TanStack Query)**:
  - `/api/course/metrics`: `points` 를 queryKey 로 하는 `useQuery`. 기존 `requestSequence` 경쟁 방지 로직을 TanStack Query 의 자동 staleness 처리로 대체.
  - `/api/course/recommendations`: 버튼 트리거 `useMutation`.
  - `applyRecommendation`: `queryClient.setQueryData` 로 캐시 시딩 → 불필요한 재요청 방지 (기존 동작 재현).
- **토스트**: 모듈 레벨 스토어 + `useSyncExternalStore` 로 기존 `useToast` 싱글턴 그대로 재현. `showToast()` 를 액션에서 직접 호출 가능.
- **Tailwind v3.4 채택**: shadcn 호환성/안정성 우선 (v4 대비 사례·검증 풍부).
- **아이콘**: MDI → lucide-react 로 대체.
- **테마**: Vuetify runningLight 테마 색상(primary #16a34a 등)을 Tailwind CSS 변수로 이식.
- `utils/distance.js` 는 미사용 dead code → 제거.
